# Scrapbook 20/10 🍒💗

Website scrapbook tặng hội bạn cũ. Chạy như một website tĩnh, phù hợp đăng miễn phí trên GitHub Pages.

## Chạy thử
Mở `index.html` trong trình duyệt. Để thử gần giống website thật hơn, có thể dùng VS Code + tiện ích Live Server.

## Thay ảnh lớp mình
1. Mở thư mục `photos/`.
2. Thay các ảnh bằng ảnh của lớp, giữ tên file: `photo1.jpg`, `photo2.jpg`, ... `photo8.jpg`.
3. Nên dùng ảnh JPG/JPEG và cân nhắc hỏi ý kiến bạn bè trước khi đăng ảnh riêng tư hoặc ảnh dễ khiến ai đó ngại.
4. Ảnh trong phong thư dùng `photo1.jpg` đến `photo6.jpg`; album dùng `photo1.jpg` đến `photo8.jpg`.
5. Ảnh chưa có sẽ hiện khung mẫu thay thế.

## Thêm nhạc
Đặt file nhạc mà bạn có quyền sử dụng tại `assets/music.mp3`. Người xem phải bấm nút “Bật nhạc” trước vì trình duyệt điện thoại thường chặn tự phát âm thanh.

## Quan trọng: để lời nhắn đồng bộ cho cả lớp
GitHub Pages không tự lưu được lời nhắn gửi lên. Bản thử này lưu bằng `localStorage` nếu chưa cấu hình backend — nghĩa là lời nhắn chỉ có trên trình duyệt/thiết bị đó, KHÔNG phải lời nhắn chung cho tất cả mọi người.

Muốn giống tính năng bình luận, để người này gửi rồi người khác mở web cũng đọc được, cấu hình Supabase:

1. Tạo project miễn phí tại https://supabase.com/
2. Vào **SQL Editor**, chạy SQL sau:

```sql
create table public.messages (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 35),
  message text not null check (char_length(message) between 1 and 700),
  created_at timestamptz not null default now()
);

alter table public.messages enable row level security;

create policy "Anyone can read messages"
on public.messages for select
to anon
using (true);

create policy "Anyone can post messages"
on public.messages for insert
to anon
with check (
  char_length(trim(name)) between 1 and 35
  and char_length(trim(message)) between 1 and 700
);
```

3. Trong Supabase, vào **Project Settings → API** (hoặc **Connect**, tùy giao diện) và lấy Project URL + public/anon key.
4. Mở `script.js` và điền vào hai dòng đầu:
   - `SUPABASE_URL = "https://...supabase.co"`
   - `SUPABASE_ANON_KEY = "public anon key"`
   Chỉ dùng public/anon key. **Không bao giờ đưa service_role key lên website.**
5. Đăng lại các file lên GitHub Pages. Mở mục Sổ lời nhắn để thử gửi bằng một thiết bị, rồi mở bằng thiết bị/trình duyệt khác để kiểm tra.

**Lưu ý:** Với cấu hình trên, lời nhắn hiển thị công khai ngay sau khi gửi, đúng theo thiết kế đã chọn. Vì ai cũng có thể đăng, cấu hình này chưa có chống spam nâng cao hoặc chức năng kiểm duyệt/xoá. Nếu link được chia sẻ rộng, nên thêm CAPTCHA/rate limit trước khi công khai.

## Đăng lên GitHub Pages
1. Giải nén ZIP.
2. Tạo một repository GitHub mới, ví dụ `qua-20-10`.
3. Tải **toàn bộ nội dung bên trong thư mục** lên repository (cần có `index.html` ở thư mục gốc của repository).
4. Vào **Settings → Pages**.
5. Ở phần build/deploy, chọn deploy từ branch `main`, folder `/ (root)`, rồi Save.
6. Đợi GitHub hoàn tất, đường dẫn website sẽ hiện trong mục Pages.

Nếu repo công khai, các file HTML/CSS/JS đều có thể được xem bởi người truy cập. Không đưa thông tin bí mật vào website.
